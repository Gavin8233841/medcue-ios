# v0.8 Development Snapshot

Snapshot time: 2026-06-05 13:25 CST

## Version label

Medication Adherence App v0.8 development snapshot.

This is a competition demo milestone, not an App Store release. The app is ready for local simulator review with the current SwiftUI frontend, SwiftPM core logic, five demo medications, Today timeline, Records calendar, Risk grouping, Medical AI chat, and Settings/backup preparation surfaces.

## Included state

- Core SwiftPM package: medication models, reminder scheduling, plan audit, visit summary, risk grouping, import review, stock projection, AI request models and prompt builder.
- iOS app: Today, Medications, AI Assistant, Risks, Records, Settings, onboarding, demo seed data, local notifications, iOS 26 AlarmKit branch, HealthKit preparation and Apple account/iCloud preparation screens.
- Medical AI: Doubao Ark Responses API default adapter is wired through Keychain or launch environment. The App displays model responses as returned and constrains output style in the outbound prompt.
- Demo data: five long-term demo medications with Today tasks.
- Temporarily paused entry points: prescription OCR import and medication barcode import are visible but disabled as “开发中”.
- Onboarding: first launch now uses a dark product-demo flow with Today timeline, profile, medical AI assistance and privacy scenes. Each page has a distinct SwiftUI animation pattern instead of only changing text.
- Appearance: Settings provides system/light/dark display preference, reduced motion, larger touch-target preference and reminder photo emphasis preference.

## Verification

- `swift test` in `swift-core`: 45 tests passed.
- `xcodebuild` for `MedicationAdherenceApp` on iPhone 17 Pro Simulator: build succeeded.
- Sensitive API keys were not written into project files.
