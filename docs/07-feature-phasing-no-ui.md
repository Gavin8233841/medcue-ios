# 功能分期，不含前端 UI

> 历史分期记录：本文件不是当前 backlog。当前决赛范围、阶段门和明确非目标见
> `FINALS_PRODUCT_PLAN.md`。

## v1 初赛核心

- 用药跟踪：药品列表、计划、服药记录、漏服记录。
- 本地提醒：按用户确认的时间生成本地通知。
- 手动录入：药品名、规格、剂型、次数、时间、疗程、备注。
- 药品图片：用户拍摄或选择图片，提醒和记录时用于辨识。
- 说明书可读化：对演示药品的说明书字段做通俗解释。
- 风险关键词：从权威来源中提取“禁忌、警示、相互作用、饮食注意、不良反应”并提示确认。
- 连续记录：记录连续服药天数、漏服次数和补记次数，用于增强主动使用意愿。
- 本地隐私：默认无账号、无云端、无广告、无健康数据上传。

## v1 数据演示方式

- 选 5-8 个演示药品。
- 每个药品保存来源链接、来源字段、更新时间。
- 对非处方药可演示“按说明书生成提醒草案”，但必须由用户确认。
- 对处方药只允许“按医嘱录入和提醒”，不自动解释为最终用药方案。

## 复赛增强

- 扫码辅助录入：识别包装码或条码后填充药名、规格等字段，用户确认后保存。
- OCR 医嘱录入：识别药名、剂量、频次、时间；所有结果必须逐项确认。
- HealthKit medication 读取：读取用户授权的药品和 dose events。
- 症状记录：用户可记录不适反应，和具体服药记录关联，复诊时导出。
- 关键联系人：用户主动分享服药摘要，不默认同步。
- 时区策略：支持本地时间提醒和固定间隔提醒两种模式。

## 决赛愿景

- 药品数据库持续更新。
- 多源说明书对照。
- 家属照护协作。
- 医生或药师审核后的用药计划模板。
- 端到端加密云同步。

## 暂不承诺

- 自动判断药物相互作用的严重级别。
- 自动判断饮食禁忌是否适用于具体用户。
- 自动判断病症与药物是否冲突。
- 基于 Apple 健康数据判断药物导致生命体征变化。
- 使用 AI 给出个体化服药建议。

## 我的补充建议

- 增加“复诊摘要”：按时间导出服药记录、漏服记录、疑似不适反应和用户备注，帮助医生快速了解真实服药情况。
- 增加“漏服原因”：每次跳过时允许记录原因，例如忘记、外出、药物不足、身体不适、医生要求暂停。这比单纯打卡更能体现医疗纪律。
- 增加“家属确认但不代替患者”：老年人场景下，家属可查看用户主动分享的摘要，但不直接修改用药计划。
- 增加“高风险变更确认”：修改剂量、频次、疗程时要求用户确认来源是医生、药师、说明书还是自定义。
- 增加“药品库存提醒”：避免因药吃完导致漏服，技术复杂度低，场景价值高。

## 时区规则

- 固定本地时间：例如每天 8:00，旅行后仍按当地 8:00 提醒，适合多数生活习惯类用药。
- 固定间隔：例如每 8 小时一次，跨时区后仍按间隔计算，适合需要保持间隔的药。
- 每个药品计划必须标明使用哪种规则。
- 跨时区后只提示复核，不自动改处方或剂量。

## 隐私与加密

- 默认本地保存。
- 使用 iOS 数据保护能力保护本地文件。
- 敏感配置放入 Keychain。
- 仅在用户主动导出或分享时离开设备。
- 后续云同步必须先做端到端加密方案和删除机制。
