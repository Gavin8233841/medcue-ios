# Demo media credits

MedCue does not bundle third-party medication photographs with its demo data.
Demo medications use system symbols, while a user-selected medication photo
continues to remain local to that user's app data.

The empty `Demo*.imageset` catalogs remain only to preserve stable asset-catalog
structure for older project references. They contain no image files and are not
selected by the current demo data seeder. No generative-AI image is included in
the application or repository.
